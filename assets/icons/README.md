# Interface icons

SVG assets from [Phosphor Icons](https://github.com/phosphor-icons/core), MIT licensed.

Pinned upstream commit: `2b75f3ad12b420c9504ef05df8d2564a28f8500e`. Upstream assets are unchanged apart from a trailing newline. The muted speaker icon combines the speaker outline with a cross. The sidebar action icons combine the sidebar and caret paths with a scale/translation.
The required license is in `licenses/PHOSPHOR-MIT.txt` and is bundled with the app.
Icons are embedded at compile time; no runtime download or icon font is used.
