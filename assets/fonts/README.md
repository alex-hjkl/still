# Source Sans 3

Regular, Medium and Semibold from Adobe’s [Source Sans 3](https://github.com/adobe-fonts/source-sans), pinned to the revision and SHA-256 hashes in `manifest.json`. The full Latin, Greek and Cyrillic fonts are embedded in the application.
